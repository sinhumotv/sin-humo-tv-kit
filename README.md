# Kit de sin humo TV

Motor de vídeo del canal **sin humo TV** (Lupi, marca de agua, barra de progreso, voz por escenas, música, mezcla y portada).
Lo usa la skill `video-sin-humo-tv` de Claude: cada vídeo solo escribe `proyecto.json` y `escenas.js`.

Orden de uso: `audio.py` → `render.js pruebas` → `render.js video` → `mezcla.py` → `portada.py` → `comprobar.py`.
Ejemplos: `ejemplo/` (economía, tono tenso) y `ejemplo_grave/` (Ceuta, tono grave). Historial: `VERSION`.
